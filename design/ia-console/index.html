Can this actually run in SharePoint?

Partly. The look is reachable, but not by installing 21st.dev components into a SharePoint page — here is what each route really costs.

Route A

Out-of-the-box web parts

  • ✓No admin, no code, no maintenance
  • ✓Ships this week
  • ✗No bento grid, no glow, no motion
  • ✗Ceiling is roughly the first mockup
~3 days · 0 developers · free
Route B

SPFx web part, React

  • ✓This design, inside the SharePoint page
  • ✗SPFx 1.21 pins React 17; 21st.dev targets 18/19
  • ✗Tailwind needs preflight off + ~82 scoped selectors
  • ✗Tenant app-catalog approval, then yours to maintain
4–8 weeks · 1 developer · admin required
Route C — recommended

Standalone React app

  • ✓21st.dev, shadcn, Tailwind v4, motion — unmodified
  • ✓Azure Static Web Apps + Entra ID sign-on
  • ✓Surfaced from SharePoint by link or iframe
  • ✓This is the in-house platform you already want
6–10 weeks to v1 · 1 developer · no SPFx

Deliberately not used

Hero — Banner and Editorial card do the same job with real layout control. Code snippet — displays code, it does not run it; no use here. Embed — only if you iframe the Power BI report instead of using its own web part, and it needs the site collection allow-list. Quick chart — Power BI covers it. Weather, World clock, Maps, Kindle — filler that makes an intranet look unowned. Organization chart, Planner, Conversations — good, but they belong on the Team page, not the home page.
